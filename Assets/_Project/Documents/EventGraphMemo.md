# Event Graph Editor 開発メモ

## 1. 開発の背景と要望

### 現状
`Run Batch Event Creation` によって、イベントの構造化、シーン上のイベントの入り口と出口の作成が可能になっている。

### ニーズ
イベント間の依存関係やアイテムの入手フローを可視化したい。

### 具体的な要件
-   アイテム使用判定（例：磁石）によって、特定のイベント（例：井戸イベントクリアで入手）が実行可能になるという関係性を可視化したい。
-   イベントIDを通じて関連するため、これをノードベースで可視化するグラフエディタが欲しい。
-   「専用インタラクト」は特殊なため未分類で良い。
-   イベント、アイテムという二つの条件が存在する。
-   実装項目名＝イベント名となるノードを全て書き出す。
-   そのイベントによって実行されるイベントIDとアイテムが手に入るのであれば、それもノード上に可視化。
-   イベントの入り口と出口をコネクトで繋ぐ。

## 2. 実装プランと対応内容

### データ構造の改修
`BatchEventCreator` と `EventJsonItem` (JSONスキーマ) を拡張し、以下のフィールドを追加しました。
-   **conditions**: イベント実行に必要な条件（イベントID、またはアイテムID）。
-   **results**: イベント完了時に得られる結果（アイテムID、またはステート）。

### Event Graph Window の実装
`Window/AnoGame/Event Graph` を新規作成しました。
-   `events_batch.json` を読み込み。
-   各イベントをノードとして表示。
-   **Condition** と **Result** の関係性を解析し、依存関係にあるノード間を自動的にラインで接続。
    -   例：「井戸（磁石）」には「タコ糸」が必要 → 「タコ糸」を入手するイベントから矢印が伸びる。
-   **操作方法**:
    -   **パン (移動)**: マウス中ボタン（ホイール押し込み）、または Alt + 左ドラッグ、または背景を左ドラッグ。
    -   **ズーム**: マウスホイールスクロール。
    -   **ノード移動**: ノードを左ドラッグ。
    -   **リセット**: Toolbarの "Reset View" ボタンで初期位置・ズームに戻る。

### Batch Event Creation の更新
`Tools/Run Batch Event Creation` のロジックを更新しました。
-   JSONの `conditions` を読み取り、生成される `InstantEventTrigger` コンポーネントの `requiredItems` や `requiredEvents` プロパティに自動的に割り当てる機能を追加。
-   これにより、JSON上で設計した依存関係が、実際のゲーム内ロジック（プレハブ）に反映されるようになりました。
